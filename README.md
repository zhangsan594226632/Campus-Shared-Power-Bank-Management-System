## 一、项目概述
![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/f2d2fa2f348e44bfad50540749c176ba.png#pic_center)

### 1\.1 项目背景

随着智能手机、平板等移动设备在校园内高度普及，学生群体对临时充电需求日益旺盛。传统人工登记租借、插座分散管理等方式存在效率低、计费混乱、设备故障无法及时处理、数据难以追溯等问题。

为实现校园充电宝**规范化投放、智能化租借、自动化计费、流程化报修维修**，开发本**校园共享充电宝管理系统**。系统采用 SpringBoot \+ Vue 前后端分离架构，支持多角色权限管理，覆盖设备管理、用户租借、订单结算、故障报修、维修工单、资金充值等全业务流程，适用于高校、图书馆、宿舍区等场景使用。

### 1\.2 项目目标

1. 实现**管理员、维修人员、学生用户**三级角色权限隔离；

2. 学生可在线查看充电宝、自助租借、自助归还、在线充值、查看订单、故障报修；

3. 维修人员可接收报修工单、登记维修结果、管理维修记录；

4. 管理员可统一管理用户、设备、分类、租借记录、维修工单、充值流水等全量数据；

5. 支持多条件查询、分页、图片上传、批量操作、自动计费、事务保证数据安全；

6. 界面简洁易用，前后端分离架构，便于部署、维护与后续扩展。

### 1\.3 角色与权限说明

|角色|主要功能范围|
|---|---|
|系统管理员|用户管理、设备管理、类型管理、租借订单、维修工单、充值记录、数据统计、系统配置|
|维修人员|查看报修信息、处理维修工单、登记维修结果、个人中心|
|学生用户|查看充电宝、在线租借、按时归还、余额充值、个人订单、故障报修、修改信息|

## 二、技术架构

### 2\.1 整体架构

采用**前后端分离架构**：

- 后端：SpringBoot 提供 RESTful 接口

- 前端：Vue \+ Element Plus 实现页面交互

- 数据库：MySQL 存储业务数据

- 部署：Jar 包 \+ Nginx 静态资源代理

### 2\.2 后端技术栈

- 核心框架：SpringBoot 2\.x

- Web 框架：SpringMVC

- 持久层：MyBatis / MyBatis\-Plus

- 数据库：MySQL 8\.0

- 安全认证：JWT Token \+ 拦截器

- 工具库：Hutool、Lombok、FastJSON

- 参数校验：Validation

- 事务管理：Spring 声明式事务

- 日志：SLF4J \+ Logback

- 构建工具：Maven

### 2\.3 前端技术栈

- 框架：Vue3 / Vue2

- 工程化：Vue CLI / Vite

- 路由：Vue Router

- 状态管理：Pinia / Vuex

- UI 组件库：Element Plus / Element UI

- 网络请求：Axios

- 样式：CSS / SCSS \+ Flex 布局

- 功能组件：表格、分页、上传、弹窗、搜索、多选批量操作

### 2\.4 系统分层结构

1. Controller 层：接收请求、参数校验、统一返回结果

2. Service 层：业务逻辑、事务控制、权限判断

3. Mapper 层：数据库 CRUD

4. Entity 层：实体对象

5. VO/DTO 层：数据传输封装

6. Common 层：通用工具、异常处理、常量

7. Config 层：跨域、拦截器、分页、文件上传配置

## 四、数据库核心表设计（简要）

1. **用户表（user）**
id、账号、密码、姓名、电话、头像、角色、状态、创建时间

2. **维修人员表（repairer）**
id、账号、密码、姓名、电话、头像、状态、创建时间

3. **充电宝类型表（power\_type）**
id、类型名称、备注、创建时间

4. **充电宝信息表（power\_bank）**
id、设备编号、类型 id、电量、位置、状态（可借 / 已借出 / 故障）、图片、创建时间

5. **租借订单表（lend\_order）**
id、用户 id、充电宝 id、借出时间、预计归还时间、状态、押金 / 扣费、创建时间

6. **归还结算表（return\_order）**
id、租借 id、用户 id、充电宝 id、归还时间、使用时长、总费用、结算状态

7. **故障报修表（repair\_report）**
id、充电宝 id、用户 id、故障描述、报修时间、处理状态

8. **维修记录表（repair\_record）**
id、报修 id、维修人员 id、维修时间、维修结果、备注、审核状态

9. **充值记录表（recharge\_record）**
id、用户 id、金额、充值方式、交易号、充值时间

## 五、核心业务流程

### 5\.1 租借流程

1. 学生登录系统

2. 查看可借充电宝列表

3. 选择设备并点击租借

4. 系统校验余额

5. 生成租借订单，修改充电宝状态为 “已借出”

6. 学生可在个人中心查看租借记录

### 5\.2 归还流程

1. 学生进入个人中心，选择待归还订单

2. 点击归还，系统自动计算使用时长与费用

3. 生成归还结算单

4. 充电宝状态恢复为 “可租借”

5. 记录结算明细，完成流程

### 5\.3 报修与维修流程

1. 学生发现设备故障，提交报修信息

2. 管理员 / 维修人员查看到报修工单

3. 维修人员前往处理并登记维修结果

4. 管理员审核维修记录

5. 设备状态更新为正常，流程结束

### 5\.4 管理员运维流程

1. 录入 / 编辑充电宝信息与类型

2. 管理学生与维修人员账号

3. 监控租借、归还、故障数据

4. 统计资金流水与设备使用率

5. 处理异常订单与维修审核

## 六、核心技术亮点

1. **JWT 无状态登录**
支持多角色鉴权，前后端分离下实现安全可靠的权限控制，不依赖 Session。

2. **统一全局异常处理**
使用 `@RestControllerAdvice` 捕获系统异常与业务异常，前端统一提示。

3. **多条件模糊分页查询**
所有列表支持组合条件搜索 \+ 分页，体验接近企业级管理系统。

4. **事务保证数据一致性**
租借、归还、充值、扣费等关键操作添加事务，防止数据异常。

5. **文件上传与图片管理**
支持头像、设备图片上传，自动重命名避免覆盖，支持预览。

6. **批量操作与状态管理**
支持批量删除、批量查询、状态标签展示，提升后台管理效率。

7. **跨域解决方案**
后端配置 CORS 跨域，支持本地开发与线上部署无缝对接。
